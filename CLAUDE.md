# Project instructions

## "Reference website"
When the user says **"reference website"** they mean **https://www.sigmanursing.org/**.
Take all visual direction from it: layout, container, spacing, type, color, components.

Reference material already in this project — check these before fetching anything:
- `Sigma Nursing Design System.dc.html` — the measured system (color, type, motif, layout, components).

### Measured values (sampled from reference screenshots)
Color: indigo `#1C1656`, indigo 700 `#2E2A63`, violet `#5F53A3`, blue (CTA) `#1493D6`,
magenta `#8A278C`, cyan `#00B9DD`, ink `#1C1440`, muted `#5A5384`, tint `#EFF7FA`,
bar `#F5F6F8`, border `#DDE6EC`, input stroke `#B9C6D0`.

Type: headings/UI/buttons/stats in **avenir-next-lt-pro** (Adobe Fonts; `Jost` substitutes
when the kit is unavailable). Body copy, article titles, table cells and form values in
**Bitter**.

Layout: container max-width **1600px**, **40px** gutters (~1526px of content at 1920).
Section padding **56px** top and bottom, so each boundary sums to the reference's ~112px.
Card grid gap **36px**, carousel gap **28px**. Radius: 4px inputs/tables, 10px cards,
pill buttons. One shadow: `0 10px 30px rgba(28,22,86,0.10)`.

Motif: indigo field cut by a diagonal seam with narrow parallel magenta and cyan bands
riding it. Never fill large areas with magenta or cyan.
